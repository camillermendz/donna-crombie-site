# Donna Laggui Crombie portfolio website — bold palette version

This is the second visual direction for Donna Laggui Crombie’s responsive portfolio website. It
positions Donna as the face of her career coaching, life coaching, workshops, and speaking services.
Inspired With Grace remains as the hero concept rather than a standalone organizational brand.

## Preview

Open `index.html` in a browser, or serve this folder with any local static web server.

## Visual direction

The layout keeps the spacious, editorial rhythm of Maison while introducing the supplied bold palette
as intentional section blocks, labels, buttons, and calls to action. Warm ivory remains the neutral
base so the page still feels calm and easy to move through.

- Deep berry: `#771D50`
- Raspberry: `#972155`
- Muted teal: `#21495F`
- Ink navy: `#111B40`
- Warm ivory: `#FBF7EF`
